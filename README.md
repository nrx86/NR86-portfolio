NR86 Portfolio

A personal portfolio website created to showcase my profile, interests, skills, and projects.

About

This portfolio is a simple web project built using fundamental web development technologies. It provides an overview of my work, interests, and development journey.

Features

* Personal introduction
* Portfolio section
* Project showcase
* Personal images and visual elements
* Navigation between pages
* Simple and clean interface

Technologies Used

* HTML5
* CSS3
* Git
* GitHub

Project Structure

index.html - Main landing page
portfolio.html - Portfolio page
Image assets - Images and visual content used throughout the website

Getting Started

Clone the repository:

git clone https://github.com/nrx86/NR86-portfolio.git

Open the project folder and launch index.html in a web browser.

No additional dependencies are required.

Purpose

This project was created to apply fundamental web development concepts while building a personal online portfolio.
