## About

Welcome to my personal developer portfolio!

I'm Nikhil Raj, an aspiring software developer interested in building useful, interactive, and user-friendly web experiences.

This website is a place to document my development journey, present projects I've worked on, and share the skills I'm developing along the way.

## Features

- **Personal Introduction** — A dedicated section about me and my journey.
- **Project Showcase** — Highlights selected development projects.
- **Skills Section** — Presents my technical skills and areas of interest.
- **Responsive Layout** — Designed to provide a consistent browsing experience across screen sizes.
- **Interactive Elements** — Includes navigation interactions, scroll animations, a back-to-top control, and email-copy functionality.
- **Contact Section** — A way to connect with me.

## Run Locally

Want to explore the project on your machine?

1. Clone the repository:

   ```bash
   git clone https://github.com/nrx86/NR86-portfolio.git
   ```

2. Navigate into the project:

   ```bash
   cd NR86-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No package installation or build process is required.
